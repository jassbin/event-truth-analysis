# 事件真实性分析

帮助用户判断一个事件、新闻、爆料或内幕信息的可信度。核心立场：**真实信息不是"找到一个权威说法"，而是建立一条可追溯、可反驳、可更新的证据链**。目标不是绝对真相，而是"当前证据支持的可信度判断 + 标注不确定性和待验证点"。

**分析对象是命题，不是事件。** 一个事件包含多个可分别判定的命题（如"断裂发生了"和"构成设计缺陷"）。全流程围绕命题组织：定位定语境，命题定对象，证据池定弹药，三层框架定筛选，计分定结论。

## 双通道：快筛 or 完整流程

**快筛通道**（日常、低争议、单一事实主张的事件）：只问三问——

1. **原始出处在哪？** 原文件/原视频/当事人原话，还是截图/转述？找不到原始出处的降级为"说法"。
2. **有没有独立第二源？** 不同来源能对上时间、地点、人物、数字才算；大量账号转同一个匿名帖仍是一个源。
3. **后续有没有修正？** 官方通报、当事方回应、专业核查是否推翻或补充早期说法。

三问全过且无争议 → 直接给档位（已证实/待核实/可疑）收工。**升级规则**：出现以下任一情况，转入完整流程，三问结果作为输入被吸收，不重复分析——①存在实质争议或反转信号；②涉及安全、重大利益相关方；③命题不止一个；④用户要求深挖。

**完整流程**（六步，报告骨架见文末）：

### 第 1 步 · 定位

一个表格合并回答三件事（不再分两处）：

| 项 | 内容 | 直接用途 |
|---|---|---|
| 事件类型 | 公共透明低争议 / 新兴危机早期 / 涉及自身责任 / 权斗内幕爆料 / 多账号"有鼻子有眼"型 | 决定信源策略：低争议直接用权威；涉自身责任→权威降权；内幕类→先验调低+弱信号流程（规则见 references/methodology.md） |
| 信息状态 | 刚爆出 / 争议中 / 已通报 / 已定论 | 决定结论表述强度上限——争议中不许出定论式表述 |
| 归谁管 | 自然灾害→气象应急；事故→警方；医疗→卫健；法律→法院文书；企业→公告/监管 | 决定证据池第 3 步优先检索哪些信源 |

### 第 2 步 · 命题拆解

把"这事是真的吗"拆成可分别判定的命题，每条写成一个可核验的陈述句。典型拆法：**发生了什么**（事件本身）/ **为什么**（原因定性）/ **会怎样**（现实影响）。命题数量不封顶，但每条必须具体到"能找到支持它和反对它的证据"。后续所有步骤按命题组织。

### 第 3 步 · 证据池

证据池是**双轨**的，两轨用途不同，不可混用：

- **E 轨（事实证据，E1、E2……）**："关于发生了什么"的主张，可真可假、可核验，**喂给第 4 步事实层**，并作为第 5 步维度①-⑤的打分依据。
- **A 轨（分析观点，A1、A2……）**："关于为什么"的解释框架（第三方机理分析、评论、复盘），无法核验真假、只能用逻辑（反推）评估好坏，**喂给第 4 步分析层**，并只允许进入第 5 步维度⑥。A 轨绝不作为"命题为真"的证据——"分析得头头是道"≠"有证据"。

池表格式：**证据内容 | 出处+日期+链接 | 信息层级（一手/二手/三手）| 类型（事实证据/分析观点）| 利益属性**。规则：

- 每条证据必须带出处+日期+链接；原件已消失（如视频下架）的链接到备份/权威转述并注明。
- 查不到出处的不入池，只进"待核实线索"。
- 利益相关方（当事企业、测试平台、竞争同行）的证据标注利益属性，供第 5 步维度③使用。
- **消费纪律**：入池的每一项（E 和 A）都必须在第 4-5 步被至少引用一次；未被消费的项，要么补消费，要么移出池并在"待核实线索"中说明——不许挂而不用。

### 第 4 步 · 逐命题三层分析

对每个命题跑三层筛选（方法论详见 references/methodology.md）：

- **事实层——多元输入，证据收敛**：从证据池引用编号（E1、E2……）列出支持/反对该命题的证据集；记录遮蔽信号（不记录、不披露、选择性披露、口径变化、污染反制）——遮蔽发生在事实层，把"缺失"本身作为事实记录。判定收敛到证据，分不清标"受遮蔽暂不可判定"。
- **分析层——多元解释，逻辑筛选**：列出各解释（含官方版本、爆料版本、第三方解读），**每条解释标注来源（E 几 / A 几 / 自建推理）**——E 轨来源的解释（如官方声明）自带利益属性需降权评估，A 轨来源的解释只取其逻辑、不取其结论，自建推理须说明生成依据。筛选标准：动机合理、因果清晰、多角度不矛盾（底线）、**能反推**（试金石：若解释成立，应能推出什么可观察结果？）。标出最自洽解释、被降级解释、未排除的替代原因。
- **隐蔽层——合理推测，边界约束**：对未明说的部分做合理还原；推测必须可检验、有证据约束、能反推，否则降级为叙事。无则标"无"。

简单命题（快筛已收敛的）可标注"快筛已收敛，事实层直接引用"跳过重复分析。

### 第 5 步 · 维度计分置信度

每个命题独立打分。**六个标准维度，每维 +1 / 0 / −1**：

| 维度 | +1 | 0 | −1 |
|---|---|---|---|
| ① 原始证据质量 | 有一手证据 | 仅二手互洽 | 仅三手/无原始出处 |
| ② 独立源交叉 | ≥3 个真正独立源 | 2 个或独立性存疑 | 单一源/账号矩阵同源 |
| ③ 利益方行为一致性 | 行为与命题方向一致（如间接承认） | 行为中性/矛盾 | 行为与命题相反（如坚称无问题且无动作） |
| ④ 反证与替代解释 | 无实质反证，替代解释已排除 | 反证/替代解释存在但弱 | 有强反证或替代解释未排除 |
| ⑤ 遮蔽信号 | 无遮蔽，数据公开 | 局部遮蔽 | 关键数据/原始件被遮蔽（下架、拒公开） |
| ⑥ 可反推性 | 主解释反推通过 | 部分通过 | 反推不通 |

**总分映射（预设标尺，不许拍脑袋）**：

| 总分 | 档位 | 置信度区间 |
|---|---|---|
| ≥ +4 | 已证实 | 85–95% |
| +1 ~ +3 | 部分证实/争议中 | 55–80% |
| −1 ~ 0 | 待核实 | 35–50% |
| ≤ −2 | 可疑/倾向否定 | <35% |

附加规则：核心数据被遮蔽时，无论总分多少，置信度封顶并标注"受遮蔽暂不可判定"；每个维度的打分必须注明依据的证据编号（E 几 / A 几），做到分数可沿"维度→证据"倒查。分数落在区间内取哪个值，由维度强度定性微调并说明理由。

### 第 6 步 · 存疑台账

凡命题档位不是"已证实"，必须挂台账（字段用 assets/observation-ledger-template.md）：命题、来源、证据等级、可信度、**升级/降级条件、复查时间**。升级/降级条件必须锚定第 4-5 步留下的具体缺口（被遮蔽的数据、未排除的替代解释），不许凭空设。

## 推理链（选择性强制）

不要求每步之间都强制推理，但**前段结论必须被后段显式消费**，禁止各步骤各写各的：

- 第 1 步定位的类型/状态 → 决定第 3 步检索方向和第 5 步表述强度上限；
- 第 4 步事实层证据集 → 直接作为第 5 步各维度的打分依据（引用编号，不重新罗列）；
- A 轨观点 → 只进分析层与维度⑥（可反推性），不得进维度①-⑤打分；
- 第 4 步分析层**最自洽解释** → 作为该命题的主解释进入计分；被降级解释 → 进维度④参与扣分；未排除的替代原因 → 压低总分并写进台账降级条件；
- 事实层遮蔽信号 → 进维度⑤扣分，并在台账升级条件中要求补齐被遮蔽数据；
- 档位 → 决定是否挂台账及复查触发点。

报告附一行**推理链摘要**；某结论确实未被后续使用时，说明理由。

## 报告骨架（强制）

```
0. 执行摘要 —— 先结论：各命题一句话+档位+总分（≤5 行）
1. 定位表（第 1 步）
2. 命题清单（第 2 步）
3. 证据池（第 3 步，编号表）
4. 逐命题分析（第 4 步：证据引用→三层筛选；第 5 步：维度计分表+推理链）
5. 存疑台账（第 6 步，汇总）
6. 方法与局限 —— 跳过了什么、为什么、遮蔽缺口、标尺修正说明（诚实声明）
7. 综合结论 —— 回应用户的原始问题：整合各命题档位给出事件整体的最终判断、直接回答用户最初问的那句话、给出剩余分歧点和后续观察锚点（≤5 行，不引入任何新证据新论断）
```

**论断溯源**：每个实质论断标注出自哪个方法（快筛/事实层/分析层反推/计分维度），不必复刻步骤章节顺序。第 0 节摘要必须置顶——先给结论，再给论证。

**表述纪律**：可信表述是"目前多源证据支持……，但……仍待核实"。区分判断与传播——判断可存疑记录，传播默认只限已多源证实的信息；不把未核实细节当事实转发。
