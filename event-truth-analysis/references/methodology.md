# 事件真实性分析方法论

本文件是 event-truth-analysis 技能的完整方法论，来源于一套经过多轮质疑和修正的实战分析框架。分析复杂、争议大或可能反转的事件时按需查阅。

## 1. 信息层级

优先找一手信息；二手信息用来发现线索，不直接当证据；三手信息只当传闻。

- **一手信息**：现场影像、原始文件、官方通报原文、当事人陈述、录音、合同、数据库记录、卫星图、天气记录。
- **二手信息**：媒体报道、专家解读、自媒体转述。
- **三手信息**：截图、传闻、群聊转发、二次剪辑。截图最容易脱离上下文，尤其警惕。

## 2. 证据链六问

核查一条信息时依次问：

1. **谁说的**？有无资质、利益冲突？
2. **何时何地**？时间戳、地理定位是否对得上？
3. **原始出处是什么**？能否追溯到原文件/原视频？
4. **证据是否完整**？有没有剪辑、断章取义、选择性披露？
5. **有无反证**？对立说法和解释是什么？
6. **信息是否可更新**？后续通报是否修正？

区分四种内容：**事实**（可核验的"发生了什么"）、**推断**（解释"为什么"）、**观点**（"应不应该"）、**情绪**（传播动员）。不把推断当事实，不用情绪强度代替证据强度。

事实核查工具：图片/视频反搜、地图定位、天气与日照核对、航班/船舶/交通记录、公开数据库、法院文书、企业登记、学术论文、卫星影像。

## 3. 权威降权规则

权威结论的"可信度"是**条件性的**，不是自动为真：

| 场景 | 处理 |
|---|---|
| 常规、技术性、低利益冲突事件 | 权威报道可信度高，可直接用 |
| 新兴危机早期 | 认知不足，权威也会错，可能把"暂时没证据"说成"没有" |
| 涉及自身责任、稳定叙事、信息控制 | 降权——结论可能是"管理结论"而非"证据结论" |
| 只有结论、没有原始数据和方法 | 只算"官方说法"，不算"已证实事实" |

权威信源分级：

- 有原始数据的技术机构 > 只有结论的宣传口
- 一线专业机构 > 非专业表态
- 允许独立专家复核的结论 > 单一通稿
- 有纠错记录的机构 > 从不认错的机构

判断权威结论真假看四件事：

1. **原始数据能不能看到**？只有结论没有数据，可信度降一级。
2. **有没有独立验证**？不同医院、地区、国际实验室、独立专家能否对上。单一通稿不算交叉验证。
3. **结论是否可证伪**？可证伪的结论应给出可检验条件（如"医护感染没有？家庭聚集没有？"），可证伪才可信。
4. **有没有纠错机制和利益冲突**？允许质疑和修正的机构长期可信度更高；压制早期质疑者的，短期结论大幅降权。

典型教训（新冠早期）：2019-12-31 武汉卫健委通报 27 例称"未发现明显人传人"；1 月 1 日警方处理 8 名"造谣者"；1-11 仍称无医护感染；1-20 钟南山确认人传人。当时可观察的矛盾信号（临床内部传闻、医护感染、境外筛查、信息渠道收紧而非证据变多）表明权威的确定性超过了证据能支撑的程度。正确反应是概率性判断：提高警惕、采取预防原则、不传播未核实细节、保留质疑。

## 4. 弱信号（谣言/小道消息）处理

定位：权威是**有数据但可能受激励约束的代理人**，小道消息是**无核验但可能携带局部信息的传感器**。两者放进不同证据层级，不二选一。

弱信号的价值：提供异常信号、替代解释、时间线线索、利益相关方反应、局部真实碎片。新冠早期"人传人""医护感染"传闻后来被证实，但"病毒人造""偏方"被证伪——不能整体否定，也不能整体采信。

**纳入考虑 ≠ 采信。** 把谣言拆成可核验命题再评估：

1. 多个**独立来源**是否指向同一异常（同一截图反复转不算）；
2. 细节是否**具体可证伪**（时间、地点、人物、文件、数字）；
3. 能否**解释硬数据解释不了的矛盾**；
4. 后续是否被原始证据**支持或反驳**；
5. 风险是否**重大且不可逆**——涉及生命安全可先做低成本预防，但表述为"待核实"，不传细节。

操作纪律：记录不转发、找独立第二源、重大风险用预防原则。

## 5. 账号矩阵与"有鼻子有眼"型爆料

权斗/内幕类信息通常混合三层：**可核事实**（任职、文件、会议）、**推断**（意味着什么、谁在斗）、**叙事**（动机、阴谋、下一步）。"有鼻子有眼"常来自**细节丰富谬误**——细节多不等于真。注意**幸存者偏差**：被证实的被记住，被证伪的被遗忘；看该来源长期命中率，不看单次成败。

先拆命题：事实命题（可查证）、因果命题（需证据链）、预测命题（看后续）、价值命题（不用于判真假）。

账号矩阵排查清单：

- 首发是谁？其他账号是否只是转载/截图/互相引用？
- 文本是否高度相似、发布时间密集、用词模板化？
- 是否匿名、新号、流量变现、靠"内幕"立人设？
- 是否只给结论，不给可核验细节？
- 是否长期有命中记录，还是总说"即将发生"却不可证伪？
- **谁受益于这条信息被相信？** 放风、试探、带节奏本身就是行为。

数量多不等于独立源多。十个账号转同一个匿名帖，仍然是一个源。

找破绽清单：时间线是否自洽；人物任职/亲属关系/机构名称是否准确；文件格式、编号、术语是否符合当时；地理、数字、引语是否对得上；逻辑是否跳跃；是否把"没有反证"说成"有证据"；是否给出可证伪预测。

**找不到破绽 ≠ 已证实**，只说明当前无法判定。此时用结构化存疑（见台账模板），设升级/降级条件和复查时间，不做无限悬置。

## 6. 三层框架（经修正的最终版）

### 事实层——多元输入，证据收敛

- 区分**本体事实**（实际发生了什么）与**证据事实**（能看到、记录、披露、可核验的部分）。
- 描述可以多元，事实判定要收敛。多角度描述是"输入多元"，事实结论是"输出收敛"。
- **来源属性不判真假**：官方和民间都可能真、都可能假——存在官方谣言，也存在民间谣言。来源的激励结构和纠错机制只影响先验可信度，最终仍看证据。
- **遮蔽发生在事实层**（不是分析层）。五种遮蔽类型：
  1. **不记录**：没留下记录、统计、现场证据；
  2. **不披露**：有记录但不公开、延迟公开、密级限制；
  3. **选择性披露**：只给结论不给数据、只给有利时间窗、只给部分样本；
  4. **口径遮蔽**：定义、统计标准、分类方式变化，让数字"看起来"不同；
  5. **污染与反制**：删帖、销毁、证人沉默、放风试探、用噪音覆盖信号。
- 处理遮蔽：记录缺失（缺什么数据、哪段时间、哪类证人）；问"这类事件正常应留下什么记录，没有就是异常"；看口径变化；找替代痕迹（审计、卫星、航班、医院记录、内部文件、境外镜像）；区分"未发现"与"不存在"。
- 分不清时标"**受遮蔽暂不可判定**"，不强行二选一，也不"各信一半"。

### 分析层——多元解释，逻辑筛选

- 动机、心理预判、因果解释属于这一层（遮蔽的**痕迹**在事实层，遮蔽的**动机**在分析层）。
- 筛选标准：动机合理、因果清晰、主流或多角度不矛盾。注意：不矛盾只是底线不是证明；动机合理的故事可能编得很顺；因果清晰可能是事后归因。
- **反推是试金石**：若解释成立，应能推出什么可观察结果？反推不通，解释降级。
- 能解释遮蔽模式，不等于证明遮蔽存在。

### 隐蔽层——合理推测，边界约束

- 对未明说的角度做合理还原。
- 补足手段：访谈、质证、交叉询问、田野调查、档案比对——补书面证据看不到的关系、动机、非正式规则，但只能作约束和线索，不能替代硬证据。
- 合理推测与阴谋论的分界：**可检验、有证据约束、能反推**。三者缺一，降级为叙事。

## 7. 判断、传播、行动分开

- **判断**：可以存疑、记录、观察，不必被迫下结论。
- **传播**：内幕类细节默认不转发；只传播多源证实且必要的信息。
- **行动**：低可信高影响 → 低成本预防但不传播；高可信高影响 → 行动；低可信低影响 → 忽略。
- 接受"概率性真实"：很多事件无法一次定论。可信表述是"目前多源证据支持……，但……仍待核实"。
