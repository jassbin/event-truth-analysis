# 存疑观察台账模板

对"找不到破绽但也不可信"的信息做结构化存疑。存疑不是无限搁置，而是**可更新、可结案**——核心是预先设定"什么证据会让我改判"。

## 台账字段

| 字段 | 内容 |
|---|---|
| 命题 | 具体到可核验的一句话（拆掉叙事，只留可查证的主张） |
| 命题类型 | 事实命题 / 因果命题 / 预测命题 |
| 来源 | 首发账号、转载链、匿名程度、该来源历史命中率 |
| 证据等级 | 原始文件 / 多独立源 / 单匿名源 / 二手分析 / 纯叙事 |
| 反证 | 对立说法、官方通报、时间线矛盾 |
| 可信度 | 低 / 中 / 待定（内幕爆料默认先低） |
| 升级条件 | 出现原始文件、多独立源、后续人事/政策印证、当事人回应 |
| 降级条件 | 时间线错误、文件造假、来源有造假记录、可证伪预测落空 |
| 复查时间 | 一周后 / 一月后 / 特定事件节点后 |
| 状态 | 待验证 / 已证实 / 已证伪 / 受遮蔽暂不可判定 |

## 示例

| 字段 | 内容 |
|---|---|
| 命题 | "某公司将于下月宣布并购 X"（预测命题） |
| 来源 | 匿名财经账号首发，7 个账号转载，文本高度相似 → 实际 1 个源，历史命中率未知 |
| 证据等级 | 纯叙事，无原始文件 |
| 反证 | 两家公司均未公告，监管披露系统无记录 |
| 可信度 | 低 |
| 升级条件 | 任一方公告、监管备案、两家公司独立信源确认 |
| 降级条件 | 下月无任何动作、首发账号有编造前科 |
| 复查时间 | 一个月后 |
| 状态 | 待验证 |

## 使用纪律

- 记录不转发：台账用于自己判断，不用于传播未核实细节。
- 定期复查：到复查时间主动核对升级/降级条件是否触发，及时结案。
- 复盘命中率：定期统计各来源"可核验命题命中比例"，据此动态调整该来源的先验可信度。
